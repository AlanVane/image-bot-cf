01

How it works

Install the GitHub App, push images to your default branch, and ImageBot opens a pull request with the lighter versions. Repeated runs update that same pull request in place — you never see duplicate PRs. Merge it (merge or squash) and ImageBot deletes its branch; if someone pushes to the imgbot branch by hand, ImageBot aborts the run politely and leaves the branch alone. Only strictly smaller files replace the originals, and every result is decode-validated first.

02

Supported formats

  • .png
  • .jpg
  • .jpeg
  • .gif
  • .svg

File extensions are matched case-insensitively.

Lossless by default; aggressiveCompression switches to lossy variants where available. Oversized images (≥8MP or ≥15MB) are handled by a separate container lane. Under the hood: svgo for SVG, lossless recompression for PNG, Huffman optimization plus metadata stripping for JPEG, and palette-preserving re-encoding for GIF.

03

.imgbotconfig reference

Place .imgbotconfig at the repository root. All fields are optional.

schedule

daily | weekly | monthly — limits PRs to at most once a day/week/month. This is ideal for projects that receive many image updates and would rather batch the optimizations together; by default ImageBot opens PRs as images arrive.

ignoredFiles

Patterns to skip. Accepts regex patterns and simple globbing. When ignoring by filename no path is necessary.

  • By extension 
    ["*.jpeg"]
  • By folder 
    ["public/special_images/*"]
  • By filename 
    ["special-image1.png", "other-image1.png"]
  • Nested folders 
    ["**/test_images/**"]
  • Path prefix 
    ["path/to/prefix*"]
aggressiveCompression

true | false (default false).

compressWiki

true | false — also optimizes images in the repository wiki. Wiki images are updated directly on the default branch (GitHub wikis have no pull requests).

minKBReduced

Minimum total KB saved before opening/updating a PR (default 10). 0 or null disables the threshold. It also limits how often ImageBot opens PRs over time.

prTitle

Custom PR title. Free for everyone in this build. Accepts any string written in GitHub markdown. Default: [ImgBot] Optimize images.

prBody

Custom PR body with {optimization_ratio} and {optimization_details} magic tags. Free for everyone in this build. Accepts any string written in GitHub markdown.

Dashboard settings

Default branch override

If you want ImageBot to look after a different branch instead of the default for the repo.

  • ↗Repo enable/disable toggle
  • ↗Manual “Request new optimization”
  • ↗Run history
  • ↗Private-repo enable limit — operators can cap how many private repositories run at once; you will see a notice if the limit is reached
05

Authorization & permissions

After installation, ImageBot requests a short-lived installation token from GitHub and uses it only to read image files, push optimized commits, and open pull requests. The requested permissions are:

  • ↗Code: read & write — to update image files
  • ↗Pull requests: read & write — to open and update the optimization PR
  • ↗Metadata: read — to list repository details

Commits land as the ImageBot bot with a verified signature (green Verified badge). If the required permissions ever change, GitHub will ask you to accept them first.

You can uninstall the GitHub App at any time to revoke all access immediately.

06

Configuration example

A complete .imgbotconfig with each available field: 

{
  "schedule": "weekly",
  "ignoredFiles": [
    "*.jpeg",
    "public/special_images/*",
    "special-image1.png",
    "other-image1.png",
    "**/test_images/**",
    "path/to/prefix*"
  ],
  "aggressiveCompression": false,
  "compressWiki": true,
  "minKBReduced": 10,
  "prTitle": "[ImgBot] Optimize images",
  "prBody": "Saved {optimization_ratio}\n\n{optimization_details}"
}
